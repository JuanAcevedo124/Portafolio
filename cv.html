03 Proyecto principal

MediSalud: sistema de gestión de citas médicas

Java + MySQL + Docker

Campuslands · Proyecto final del curso de Java · 2026 · github.com/JuanAcevedo124/Gestion-de-citas-

Aplicación de consola para administrar pacientes, médicos, citas, historias clínicas y facturación de una clínica, organizada por capas (entidades, repositorios, servicios, controlador y vista) con base de datos MySQL en Docker.

  • Agendamiento y cancelación de citas con motivo, y ciclo de estados validado con el patrón State (excepción ante transiciones inválidas).
  • Facturación con tarifas por tipo de consulta (Strategy) y recargo nocturno o descuento para afiliados (Decorator).
  • Notificaciones de cambios de cita con Observer ejecutadas en un hilo en segundo plano; códigos generados de forma segura con AtomicLong.
  • Historia clínica construida con Builder y punto de entrada simplificado para el agendamiento con Facade.
  • Persistencia con JDBC y DAO por entidad, respaldo en archivos y serialización, y migración SQL para nuevas columnas.
  • Reportes con Stream API: citas, facturación y cancelaciones por médico, y pacientes por rango de edad.
